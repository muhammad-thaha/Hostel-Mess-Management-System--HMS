# HMMS Backend

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Create a `.env` file (already provided) and set your MongoDB URI if needed.
3. Start the server:
   ```bash
   npm start
   ```

The backend will run on `http://localhost:5000` by default.
